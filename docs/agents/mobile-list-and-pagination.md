# PVX 移动端列表与分页维护规则

## 适用范围

普通 Web Vue 在手机浏览器、小程序 WebView 和 App WebView 中的列表、分页、表格与相邻导航。终端统一规则见 `unified-webview-routing.md`。

## 分页统一规则

- 三个及以上页面共用 `src/mixins/responsive-pagination.js`，手机断点为 `720px`。
- 桌面 `pager-count` 为 7，手机为 5；不得按 `.v-miniprogram` 改变数量。
- 手机隐藏 `total` 与 `jumper`，保留上一页、页码、下一页。
- 手机分页按钮使用约 `30px` 的稳定尺寸和小间距，分页整体居中且不得制造页面级横向滚动。
- 已接入页面：坐骑、奇遇、宠物、家具、书籍。科举题库当前使用同等行为的页面内响应式状态。
- “加载更多”与分页可同时存在，但必须共享页码、加载态和请求结果，不能重复追加。

## 列表交互约束

- 数字 `0` 是有效筛选值，查找分类必须使用严格相等；不能让 `0` 与“全部”的空字符串互相匹配。
- “查看全部”必须同步顶部筛选组件、当前分类和请求参数，避免筛选组件的延迟事件把页面重置回总览。
- 移动端字段列表优先转为信息卡。书籍列表隐藏桌面表头，标签列固定为紧凑宽度，值列允许换行。
- 书籍名称在手机端使用“图标 + 名称”横排；桌面仍可竖排。移动状态由父页面显式传入，不依赖深层样式覆盖第三方组件内部结构。
- 移动端信息卡自身负责边框和圆角，外层表格容器不得再叠加边框造成双角或双线。

## 相关移动端细节

- 题目详情的上一题/下一题在手机仅保留图标；返回按钮保留有边框样式，文案为“返回列表”。
- 金价图手机端均价标签和左侧数轴标签放到对应参考线上，并收紧左右 Grid；桌面图表配置保持不变。
- 成就明细手机端标题、完成数与“只看未完成”分层排列；筛选控件左对齐并具有独立触控表面。
- 成就表格保留完整业务列，通过受控容器横向滚动；容器需设置最大宽度、触摸惯性、滚动边界和可见滚动条，不能让整页横向滚动。

## 验收

- 至少检查 `320px`、`390px`、`414px` 和 `720px`。
- 首尾页、单页、超过 7 页以及加载中的分页均不截断。
- 横向表格只在表格区域响应左右滑动，页面主体宽度不变化。
- 点击分类“查看全部”后，选中态、标题、总数、列表和请求类型一致。
