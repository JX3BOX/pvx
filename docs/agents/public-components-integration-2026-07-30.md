## 3. `@jx3box/jx3box-ui` 接入

### 3.1 已完成

- [x] `PvxUser` 向 WikiPanel、WikiRevisions、WikiComments 统一传递 variant。
- [x] 普通 Web 使用 `surface`，机器人输出继续使用 `default`，避免改变抓图结构。
- [x] 书籍、家具、坐骑、宠物、声望详情删除已由公共组件承担的 WikiPanel 深层结构覆盖。
- [x] 删除的覆盖包括 panel head/body/title/actions、评论正文容器和移动端重复内边距。
- [x] 保留真正属于 PVX 页面层的 Grid、区块间距、社区外框排布和业务按钮品牌色。

### 3.2 i18n 边界

- WikiPanel、WikiComments、WikiRevisions 的固定界面文案由 `jx3boxUi.*` 维护。
- PVX 通过现有宿主 i18n 实例合并公共库词条，不创建第二套语言状态。
- 用户正文、贡献说明、NPC、地图名和其他游戏源数据不由公共组件强制翻译。
- 机器人场景继续使用公共组件默认 variant，普通 Web 的 PVX surface 不得改变机器人输出。

### 3.3 后续

- [ ] 统一评估各详情主题仍保留的 `.u-btn--link` 品牌色是否可以改用公共组件 CSS Variable。
- [ ] 在公共组件 API 稳定后继续减少消费者对内部 class 的依赖。

## 4. `@jx3box/jx3box-facedat` 接入

### 4.1 已完成

- [x] 删除 `FaceBodyDataViewer.vue` 中完整的 Facedat 主题副本。
- [x] 删除 Face/Body 解析页中针对 Tab、贴花列表、参数、价格、Slider 和移动端滚动的深层覆盖。
- [x] 删除普通 Web 详情页中重复的 Facedat Tab 内部修正。
- [x] 保留页面预览区最小高度、详情模块间距等宿主布局职责。

### 4.2 接入原则

- Facedat/Bodydat 的字段、参数组、贴花结构和组件主题由 `@jx3box/jx3box-facedat` 维护。
- PVX 不再复制公共库的完整内部 DOM 样式。
- PVX 只处理公共组件所在页面的宽度、间距、模块顺序和终端分流。

## 5. `@jx3box/jx3box-map` 接入

### 5.1 公共能力确认

- [x] 支持 `focus`、`overview`、`responsive` 模式。
- [x] 使用 `ResizeObserver` 响应容器变化。
- [x] 提供 resize/error 等事件和图片加载失败重试状态。
- [x] 提供地图、点位可访问名称和键盘焦点。
- [x] 地图加载、失败、重试、子地图切换等固定 UI 使用公共库四语言词条。

地图名、NPC、坐标和点位说明仍属于业务源数据，由 PVX 传入，不由地图库猜测翻译。

### 5.2 宠物详情

- [x] 只有存在地图数据时才为宠物详情添加 `has-map`。
- [x] 无地图宠物使用“宠物卡片 + 资料”双列，不再预留空白第三列。
- [x] 竖屏平板及手机统一降为单列，避免宠物卡片和字段区横向溢出。
- [x] 修复模板读取未定义 `petWiki` 的 Vue 警告，成就 ID 从宠物数据安全读取。
- [x] 社区区块补充单列收缩约束，避免 Wiki surface 接入后撑宽页面。

### 5.3 声望详情

- [x] 声望商人点位优先使用 `Guides[0].map`，避免把 NPC 坐标绘制到错误的 `szMapIDs` 地图。
- [x] 不再强制覆盖 `.c-map__inner` 的 1024 × 896 聚焦画布宽高。
- [x] 声望商人地图并入“声望资料”卡片，不再作为顶层独立整行卡片。
- [x] `>1440px` 时资料与地图在同一卡片内左右排列并顶部对齐。
- [x] `≤1440px` 时地图在同一卡片内下移，整个商人模块与资料区左边缘对齐。
- [x] 上下布局的商人模块限制为 960px 安全宽度。
- [x] 聚焦地图画布在容器内水平居中，避免只在右侧露出空白背景。
- [x] 地图在手机、平板、中等桌面和 2K 大屏均保留，不因适配困难隐藏业务内容。
