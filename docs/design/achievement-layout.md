# 资历宝典页面设计规范

> 最后更新：2026-09-07。本文记录当前确认的最终交互，不保留被后续反馈替换的中间方案。

## 1. 适用范围

本文描述普通 Web 资历宝典 `/achievements`、`/achievements/compare`、`/achievements/leap` 的新版信息结构、视觉语言和响应式规则。业务状态、接口边界和实施阶段见
[`../project/achievement.md`](../project/achievement.md)，统一字段协议见
[`../agents/achievement-workbench-data-contract.md`](../agents/achievement-workbench-data-contract.md)。

新版以“魔盒成就百科”交互原型及确认稿图 1 为功能与结构参考。旧资历宝典代码、侧栏和深色国风背景不再是保护对象。

## 2. 页面骨架

三页必须共享同一个工作台外壳：

1. 站点公共导航与 Header；
2. 暖纸色工作台容器；
3. “完成进度 / 亲友对比 / 渡劫方案”顶部页签；
4. 独立的“资历宝典使用指南”入口；
5. 当前路由的业务内容；
6. 公共返回顶部与 Footer。

模块页签在所有 Web 断点保持顶部布局，不再切换为桌面侧栏。页签支持键盘焦点、明确激活态和移动端横向滚动；使用指南在窄屏可收敛为图标按钮，但必须保留可访问名称。

## 3. 视觉语言

-   页面底采用低对比暖纸色，可使用细微纤维纹理和青灰色晕染，不使用大面积深色游戏背景；
-   主内容表面以米白、浅暖灰为主，边框低对比、阴影克制；
-   主强调色使用黛青/青灰，第二强调色使用暖金；
-   状态色仅用于完成、警告、绝版、隐藏和错误等语义，不作为大面积装饰；
-   数字使用等宽或制表数字特性，进度、点数、成本等级应易于纵向比较；
-   允许原有游戏图标、角色头像和业务美术继续出现在内容区，但不决定新版外壳配色。

## 4. 三页信息结构

三页的难度展示共同遵守以下规则：维度名称、顺序和显示项只取公共维度定义；接口不可用时才回退内置五维。综合难度（`overall`）始终以支持小数填充的五颗星表示，星级后显示一位小数（如 `0.5`），不使用“0星”等整数档位文案覆盖真实分数。其他维度配置了 `score_labels` 时按区间展示文案，下限包含、下一档下限不包含，按原始分数匹配，不四舍五入后分档；悬浮提示保留具体分数。没有匹配文案时回退为相同的星级展示。星级不显示可见的 `x/5`；供辅助技术读取的 `aria-label` 可以保留 `2.5/5`。星级模式下 `0` 显示为空星和 `0.0`，只有 `null` 或非法值显示“—”。所有成就入口及亲友对比导出均隐藏同步完成率和角色样本计数；角色自身进度、方案完成率保留。成就名称下显示真实描述，长文案允许换行，缺少描述不显示空占位。

成就元信息按实际数据存在性展示：没有地图名时不渲染地图块，没有奖励引用时不渲染奖励块。常规成就不显示“常规成就”档位 tag，五甲档位 tag 保留；业务标签中的门派标签排在节日、活动、阵营及其他标签之前。分类名、标签、门派限制和备注都不能用占位文案制造业务含义。

### 4.1 完成进度

按以下顺序实现：

1. 当前角色、排序和筛选；
2. 总资历、总完成率、已完成成就数；
3. 常规、五甲、隐藏、绝版等分类总览；点击常规或五甲卡片直接修改主页面成就列表的档位筛选，隐藏卡片跳转 Wiki 的隐藏成就维护文章，绝版卡仅展示统计；
4. 主页面的成就列表顶部提供档位、完成状态、地图、排序、搜索和重置；档位仅包含常规、五甲两项并默认常规，排序默认保留原始目录顺序，同时提供未完成优先等排序选项；重置恢复常规档位、全部状态、全部地图、默认排序、空关键词和全部分类；分类由左侧分类进度列表直接控制，不重复展示分类下拉；右侧列表标题不追加“成就”，一级分类直接显示一级名称，二级分类显示“一级 / 二级”，选择全部时显示“全部”；
5. 分类进度恢复旧版一级分类图标；桌面展开一级分类后采用左侧一级目录、右侧二级目录的主从双栏，左栏仅保留图标、名称、完成率和进度条，窄屏降级为上下布局；一级和二级分类都可联动筛选全部成就列表；
6. 难度维度按公共定义动态展示；默认只读取当前可见页，用户主动选择某一维度排序时才补齐当前候选集，补数失败则保留原排序并提示。

成就列表继续保留奖励信息。当前页存在奖励引用时展示奖励字段：物品奖励加载图标、详情悬浮卡片和物品链接；无法解析的其他奖励使用通用奖励标识，加载失败显示不可用提示。没有奖励引用的记录不渲染奖励块。奖励物品按当前页批量读取并复用会话缓存。

总览与分类总览采用紧凑高度，并允许整体折叠。折叠入口位于角色栏右侧；折叠后保留角色切换、同步状态和展开入口，不影响当前角色、分类或成就筛选状态。分类与列表顶部对齐、随内容自然增高，整页纵向滚动，每页 15 项；折叠态不再限制工作区高度。展开二级分类后恢复一级、二级主从双栏。

主页面的分类筛选和分类进度沿用旧版目录口径：仅展示包含 `general=1` 常规成就的顶层分类，排名、江湖百态等仅包含其他档位成就的辅助目录不进入主分类。未展开二级分类时，一级分类只使用单列，不为了填满宽度拆成两列；目录随内容展开，不设置内部纵向滚动。

常规和五甲成就不设置独立二级路由；两张分类总览卡片与主列表档位下拉使用同一个 `filters.tier` 状态，点击卡片后 URL 不变，并立即刷新下方列表。隐藏成就不参与档位筛选，分类总览卡片跳转到 Wiki 隐藏成就文章；绝版成就不参与档位筛选，也不提供点击入口。

常规卡片和常规列表只统计 `general=1`、`visible=true` 的成就，零资历常规项保留。`general=3` 使用独立的内部特殊档位，不因可见性或兜底逻辑混入常规、隐藏档位，目录、搜索和地图结果使用一致分类。页面顶部总览与左侧“全部”继续汇总全档位，不随右侧档位筛选变化。

### 4.2 亲友对比

-   对比列表只包含常规可见成就（`general=1`、`visible=true`），保留零资历成就；分类数量、当前结果数量与资历、分类分析和交叉统计均使用这一口径。搜索、地图筛选及导出也必须限定在同一目录范围。角色概览、矩阵表头及总资历对比使用全档位总资历，与完成进度总览一致。
-   当前角色沿用完成进度页最近选择的本人角色并固定为首个基准角色，不提供移除入口，父页面删除逻辑也必须拒绝该角色；其余本人角色和亲友角色支持添加、移除与批量对比；
-   对比角色采用紧凑概览并支持整体折叠；折叠后保留添加角色和展开入口，且不清空当前角色、分类或筛选状态；
-   成就状态、地图、搜索、重置与导出统一放在对比矩阵顶部；状态筛选保留“共同未完成（推荐组队）”“共同已完成”和各参与角色的“未完成/已完成”组合，冲突条件不可同时选择；添加角色归入角色概览，避免在筛选区重复；重置清空完成状态、恢复全部分类、全部地图和空关键词；
-   完成状态默认显示“全部状态”，取消独立漏斗图标，使用与“全部地图”相同的正常文字颜色、220px 桌面宽度和控件样式；保留原有多选、冲突禁用与重置语义。当前结果的成就总数和可共建资历仅集中在矩阵标题右侧展示，分类标题、筛选区和成就名称表头不重复展示总数；分类条目自身的数量继续保留。
-   分类与完成进度保持相同的主从语义：未选择一级分类时为紧凑单列，选择一级分类后左侧保留一级目录、右侧展示二级目录；一级和二级分类都直接联动矩阵标题与结果；
-   对比与完成进度统一每页 15 项，分类与矩阵顶部对齐并随内容自然增高，整页纵向滚动；不再设置固定工作区高度、内部纵向滚动或悬浮遮挡条目的表头，分页跟随列表底部。折叠角色概览只收起概览内容，不改变滚动策略；
-   角色总资历不随列表筛选变化；分类完成率及交叉分析基于常规可见全集，单项完成状态、列表数量、结果资历与导出跟随当前筛选；
-   多角色横向扩展只允许发生在对比矩阵容器内，不能撑宽页面；
-   导出内容必须与当前筛选结果一致，且页面与 Excel 从同一份动态维度定义生成列，未知新维度也不能被丢弃；
-   成就图片与文字块顶部对齐；没有地图时不渲染地图，分类为空时不显示占位分类；隐藏同步完成率，成就名称下展示可换行的真实描述。

### 4.3 渡劫方案

-   方案详情按“页头 / 方案概览 / 咨询记录 / 方案成就”组织，统一紧凑留白和卡片圆角。方案名只在详情页头显示一次，概览直接使用“方案概览”标题；本地编辑时仍显示编辑方案名。
-   页头保留唯一“渡劫咨询”入口，下方仅展示“咨询记录”、历史详情及分页，不再重复“咨询专家”按钮；空记录使用简短文字，不显示大幅空态插画。记录组件持续挂载，保留无记录、失败重试及已有待回复咨询分流能力。
-   成就表使用“方案成就”标题及“筛选和排序仅影响当前展示，不会修改方案”说明，移除开发侧的接口、维度来源和评分公式说明。表格局部横向滚动，不以过大的固定最小宽度强制宽屏横滚；方案成就参照已入选清单采用连续分列布局，分类与地图合并到名称下方，描述与图标左边缘对齐；完成状态、资历、难度及操作垂直居中，推荐分组不展示。表头独立吸附并同步列表横向滚动，保留分页、筛选及可选标签、门派限制、备注字段。
-   保留方案列表、创建、编辑、删除和详情流程；
-   方案详情头部在桌面保持单行：返回入口、详情标题、方案名与操作同层展示；外层保留高度统一、宽度随文案紧凑适配的“成就团长指点”和“更多”按钮，编辑与删除收进“更多”，展开项沿用 OS 表格的完整等宽按钮形态（当前最小宽度 `88px`）；官方方案的“更多”仅展示“复制为我的方案”；窄屏允许头部操作换行；
-   渡劫方案主页以“系统推荐渡劫方案”为主工作区，直接展示方案名称、目标资历、当前角色、成就分类、维度偏好、方向偏好与推荐结果。主按钮为“开始推荐”；右上角“方案列表（数量）”打开方案管理抽屉，保留分页及详情入口。分类、维度和方向偏好的重置不清空基础设置；
-   系统推荐请求后端，由服务端给出候选资格、分组、初始顺序、当前资历和阶段。分类与权重设置作为偏好提交；前端补充展示信息并维护玩家调整后的草稿，不重新执行 `stage-v1` 评分或本地门派过滤；旧规则仅保留在纯函数与历史方案兼容说明中；
-   主页设置区标题为“偏好设置”，维度折叠区标题为“维度偏好”。成就分类默认展开，“全部分类”作为第一张卡片放在“杂闻”等具体分类之前，使用同一网格和选中样式，不独占整行；分类卡片按可用宽度多行排列，手机两列。不显示“勾选愿意做的方向”、全部分类操作说明等常驻提示。每张卡片将勾选框、完成进度图标、分类名称和右对齐的未完成数放在同一行。分类图标与完成进度共用 `achievementCategoryImages` 资源表；选中态采用黛青单线描边与浅暖灰底，键盘焦点只标记勾选框，不在鼠标点击后留下卡片外圈。未完成数只统计角色同步记录中有资历奖励的普通可见成就，按 ID 去重，不再使用前端 `school-v1` 扣减。各分类门派排除数必须来自服务端；当前推荐响应仅有门派或体型排除合计，分类数量悬浮说明中暂显示“门派排除 —”，不显示常驻统计说明；未完成数口径仍为尚未扣除推荐限制的原始数量；
-   方向偏好仅显示所选分类对应的方向，同一方向合并显示；只选一个分类时保留其方向设置，未选分类时隐藏方向分区。方向采用“降低优先级 / 跟随资历阶段 / 优先”三档等宽文字单选，默认中间档，无“排除”档。取消分类清除对应方向的自定义偏好；重新选中恢复中间档。界面未展示的方向始终提交 `1`；
-   推荐维度偏好使用三档文字单选，隐藏倍率和连续滑杆，默认选中间档。金钱为“尽量不花钱 / 能省就省 / 不差钱”，时间为“少肝一点 / 适当肝肝 / 不怕肝”，运气为“少看点脸 / 随缘试试 / 不怕看脸”，性价比为“划算优先 / 兼顾收益 / 拿到就行”，综合难度为“轻松一点 / 难点也行 / 难度无所谓”。这些选择只影响推荐先后，不直接排除成就；界面不显示解释性提示。维度标题在上、三个等宽选项在下，长语言允许换行；维度仍按公共定义动态展示。未知维度及成本维度推荐方向反转时使用“很在意 / 看情况 / 无所谓”的通用文案；
-   主页采用上下布局：基础设置在桌面三列排列，分类卡片网格使用整个内容宽度，维度与方向内的三段选项按宽度分列，少量项目保留正常列宽及空列，不能拉满整行，推荐结果在下方自然展开。手机端偏好设置可整体折叠，点击“开始推荐”后收起设置并保留结果。打开或关闭方案列表、进入已有方案详情再返回均保留推荐顺序、入选成员、筛选及基础设置；编辑或复制已有方案使用独立表单，保存或放弃编辑后恢复推荐表单。切换角色、客户端或修改偏好仍使旧推荐失效；
-   推荐预览区分当前候选和待开放活动，每个页签只展示一个连续列表，移除分组翻页、索引、标题和同地点折叠区；初始顺序按地点首次出现顺序聚拢同地点的不同成本档，保留原组内顺序，场景与世界地图 ID 分别处理。详情、难度与标签按列表顺序分批加载，已加载的连续条目先行展示；各类请求独立显示失败和重试，展示数据缺失不改动推荐顺序与资格。待开放活动不进入当前保存清单；
-   推荐主列表在桌面使用带表头的分列布局，资历和各难度维度独立对齐，操作按钮与数据列垂直居中；表格上方不再重复增加分隔线。表头随整页滚动吸附在推荐操作栏下方，位置跟随操作栏实际高度；窄屏横向滚动时表头与数据同步，手机仍保留紧凑换行条目。返回顶部按钮层级高于底部创建栏，保持完整可见和可点击。
-   推荐摘要显示服务端快照时间，不显示时区后缀，时间缺失或非法时显示“同步时间未知”；“查看同步指引”新开站内统一指南的同步章节并保留当前草稿，明确提示玩家完成游戏内同步后再刷新推荐。刷新推荐本身不执行同步；
-   待开放活动使用公开标签名称和服务端开放时间，名称缺失时保留标签编号，时间缺失时提示未知；排除原因提供可展开的分项计数，未知原因仍可见，各原因可能重叠，不展示推算的去重排除总数；
-   推荐结果随整页纵向滚动，成就列表自然撑高，不设置独立滚动区；顶部吸附栏使用紧凑横排，标题、入选项数与资历、预计达成与目标差额、查看候选、增加成就、重新生成和撤销调整尽量同排；不另设摘要卡片，不显示重复的保存说明。清单标题、活动切换和当前展示数量放在筛选下方随正文滚动。桌面吸附位置通过外壳的 `--achievement-sticky-top` 跟随页签高度，手机页签不吸附，因此仅避开站点导航；手机操作区保留 40px 点击高度并换行。主列表仅展示已入选，摘要右侧的“查看候选（数量）”按钮打开独立弹框，仅展示尚未入选的成就；候选为空时提供空状态。移除重复的“当前推荐”页签与范围切换，待开放活动仅在有内容时显示入口。同步说明、排除统计及筛选随正文滚动，底部创建入口保持可见。手机吸附栏将操作收为带可访问名称的图标按钮，收起重复的保存提示；筛选或切换查看范围后，首条结果定位到吸附栏下方。
-   “查看候选”右侧新增“增加成就”，打开当前角色全部可添加的未完成普通可见成就目录，使用 `general=1`、`visible=true`、正资历和 `school-v1` 本地可完成口径，不受推荐偏好或服务端候选范围限制。已入选成就保留在目录中，标记“已在入选清单”并禁用选入；选入确认后保留原清单、追加新项目并立即更新数量与资历，撤销调整恢复初始推荐。推荐池外手动增加项以独立 `manual:<id>` 分组保存，展示名称为“手动增加”，不推断同地图关联；该入口只确认单个成就。
-   增加成就及方案编辑的添加弹窗与查看候选统一使用 1100px 弹窗、顶部分类／地图／名称筛选栏和与已入选清单一致的分列成就表，表头吸附在弹窗滚动区域顶部并与横向滚动同步；资历与各难度维度独立成列，选入与删除按钮集中在操作列，手机保留紧凑换行布局；复用同一条目组件与选入按钮样式，不展示左侧分类进度或卡片布局。增加成就每页 15 项，列表独立滚动，分页固定显示在弹窗底部；移除重置与完成添加按钮，保留已入选禁用标记。其筛选独立于推荐主列表，查看候选仍与主列表共享筛选。资历宝典内所有弹框及操作确认框支持拖拽标题栏移动。
-   所有选入、删除均先弹出确认框，默认“仅此成就”，可改选“相关成就”，预览成就及数量；相关组按后端原始地点聚合，同地图不同成本档视为同组，场景与世界地图 ID 分离，排序不改变关联关系。整组操作只作用于发起操作的名单，不跨已入选与候选；取消确认不改草稿。
-   推荐预览支持在连续列表中拖动项目、删除和撤销调整；撤销恢复初始的同地点相邻顺序，待开放活动在条目中展示活动名称与开放时间；主列表与候选弹框共用名称、地图、分类筛选，不以当前可见结果作为保存内容；
-   初始推荐使用后端当前资历，按草稿顺序选取达标所需的最短前缀；手动选入和排序保留入选成员；已入选移除后若预计总资历低于目标，会保留其余已入选项目并从完整候选池按草稿顺序补足缺口。候选选入是额外添加，保留原有入选，允许超出目标；已入选删除回到候选，并在不足目标时自动补入；候选删除仅移出候选池。保存完整手动清单，不能按目标再次截掉额外项目。显示入选数量、预计获得、预计达成资历和目标差额；所有实际入选项点数均需完整，手动清单不足目标仍可保存；
-   已保存方案及咨询中的方案列表、详情、进度和本地编辑统一使用 `general=1`、`visible=true`，读取历史方案保留零资历常规项。本地添加只取当前角色未完成、资历点数大于 `0` 的普通可见成就。分类按名称合并、ID 去重，未完成数量为 `0` 的分类隐藏；该兼容口径不用于二次过滤后端推荐结果；
-   角色“当前资历”及完成进度“总览”仍统计全部已获得资历，咨询中的完成进度也保留全档位总览与各档位卡片；常规卡片及默认列表只展示常规可见项。方案自身统计只计算方案内的常规可见成就，预计达到值使用全部当前资历加上方案可增加资历；
-   所有“增加成就”入口先读取完整候选的公共标签，用接口 `tag_type=mount` 的 `tag_value.operator/values` 过滤非本门派可完成项；过滤后再统计目录和分页，选入时复核。接口门派规则优先，没有规则时才使用显式 `restriction.school` 及 `school-v1` 目录回退；不从“门派：…”标签文案或可学习体系猜测限制。标签请求失败时提供重试并阻止选入，难度失败不阻止；后端已有推荐清单和角色统计不受此新增筛选影响。
-   进入本地编辑态的路线允许增删成就，重复项不可添加；每次变更同步重算清单项数、预计获得、达成后资历、目标缺口、耗时、难度和成本汇总，保存内容以调整后的路线为准；方案查看详情保持只读；
-   方案管理抽屉宽度不超过 880px，使用紧凑响应式卡片：桌面两列、手机单列；卡片不展示通用方案图标，来源标签放在标题前，描述固定展示在标题下方且缺失时显示“—”，其后展示三项核心数据和完成率；整张卡片支持点击或键盘进入详情，列表不保留查看、编辑、复制或删除操作；已有方案的编辑、删除和复制入口集中在详情页，官方推荐使用暖金标识，玩家方案使用黛青标识；
-   路线表按公共定义动态展示和排序难度维度，所有维度采用 `0~5` 等级的低分优先语义；公共接口没有成本档字段，因此不显示成本档筛选，也不在前端推导；
-   同步完成率整列隐藏；标签、门派限制和路线备注等可选整列仅在当前表格至少一条记录有值时出现；单条记录没有地图时仍不显示地图，名称下补充可换行的成就描述；
-   推荐使用公共详情、难度和标签数据增强展示，已保存方案与本地编辑路线使用相同公共维度定义；显示层不自行补写后端推荐规则；
-   写操作需要明确确认、失败反馈和可恢复路径；删除方案必须二次确认，仅在删除成功后自动返回方案列表。
-   “成就团长指点”已接入咨询服务，仅本人正式服方案显示入口；可选择角色和专家、提交问题、查看当前方案及角色完成信息、接收建议和评价。已有待处理咨询时进入该咨询详情；当前交互不包含双版本方案改写。
-   咨询详情的“当前方案”复用已入选清单的条目与表格样式，保留独立的完成状态列、筛选、排序和分页，关闭拖拽及增删操作。标签、门派限制和备注按实际内容放在成就信息下方，不单独占列或显示空占位；表头吸附位置跟随咨询页面外壳，手机按同一条目组件换行展示。

## 5. 响应式规则

-   页面根节点不得出现整体横向滚动；
-   桌面内容充分使用可用宽度，不设置旧版 `960px` 固定内容宽度；
-   平板工具栏允许换行，筛选项保持清晰分组；
-   手机页签可横向滚动，指南按钮固定可见；
-   表格、对比矩阵和分类长列表只在自己的容器内滚动；
-   触控按钮高度不低于 36px，核心操作建议不低于 44px；
-   长角色名、服务器名、成就名和四语言文案不得覆盖操作按钮。

手机端（`@phone`）补充约定：

-   顶部页签随页面自然滚动，收起装饰图标以保证窄屏文字空间；指南保留独立的 `44px` 点击区，长语言页签仍可局部横向浏览。
-   完成进度的一级、二级分类上下排列；成就卡片的描述、难度和奖励使用卡片可用宽度，避免持续挤在图标右侧。角色栏、筛选和操作允许换行，折叠总览不重置筛选。
-   亲友对比矩阵在手机端取消成就列的横向固定，并收紧成就列宽度，确保横滑可以访问所有角色列；桌面仍保留固定成就列。角色概览、筛选与添加角色弹窗分别适配窄屏。
-   渡劫方案的表单、详情操作、推荐偏好和弹窗按可用宽度重排；推荐预览中的摘要与结果保持可连续滚动，长说明不能挤掉结果区。表格保留所有业务列，仅在表格容器内横向滚动。
-   完成进度、亲友对比、方案列表和方案成就复用 `responsive-pagination` 判断手机断点；手机分页仅显示“上一页 / 当前页与总页数 / 下一页”，不渲染数字页码列表与省略按钮。翻页按钮使用 `36px` 方形点击区，分页单行居中，保留页码状态与请求行为；桌面继续显示完整页码列表。

## 6. 样式作用域

新版外壳根类统一为 `.c-achievement-workbench`，所有专有样式限定在资历宝典根节点内。完成进度、亲友对比和渡劫方案均已移除旧路由主题类；旧总览、对比、渡劫与表单主题文件，以及旧 Web 总览/分类图片素材已从项目清理。小程序/App 使用的 `wiki_miniprogram` 资源保持独立，不在清理范围内。

三个 Tab 只属于一级路由：完成进度、亲友对比、渡劫方案。二、三级路由默认不渲染 Tab 和使用指南，并移除一级外壳的边框、背景与内边距，由子页面自己的返回入口和页面容器承担导航及视觉层级。一级路由通过 `meta.workbenchPrimary=true` 显式加入 Tab 外壳；新增子路由无需额外配置，默认保持独立。完成进度不再设置常规、五甲、隐藏或绝版成就子路由，四类信息统一在一级页面完成展示和筛选；渡劫方案详情使用 `/leap/:id`，旧的 `/leap?id=...` 自动重定向到详情路由。

禁止通过修改公共 `Pvx*` 组件或全局 Element Plus 样式来完成资历宝典专有视觉。

## 7. 验收矩阵

至少覆盖：

-   `1920 × 1080`、`1440 × 900`、`1280 × 800`；
-   `1024 × 768`、`768 × 1024`；
-   `414 × 896`、`390 × 844`、`320 × 568`；
-   简体中文、繁体中文、英文和越南文；
-   未登录、无角色、加载中、失败、空数据、单角色和多角色；
-   有新字段、部分新字段和全部新字段缺失三种数据情况。

所有尺寸都需确认页签、指南入口、内容滚动、长文本和局部表格没有遮挡或页面级溢出。

### 站内使用指南

`/pvx/achievements/guide` 整合游戏成就同步与当前资历宝典操作说明，无需登录即可阅读。顶部指南入口与推荐面板同步指引均新开该页面，后者定位到 `#sync`，保留原页面方案草稿。指南按角色绑定、游戏内同步、检查时间、三页使用方法和常见问题组织，页面不展示参考原文链接；旧版虚拟角色与自选渡劫步骤不搬入。
