# 资历宝典页面设计规范

## 1. 适用范围

本文描述 `/pvx/codex/achievement` 普通 Web 的视觉资产、页面层级和响应式规则。业务状态、统计口径和专用端边界见
[`../project/achievement.md`](../project/achievement.md)。

通用 PVX 设计仍以 [`pvx-visual-style-guide.md`](./pvx-visual-style-guide.md) 和
[`responsive-adaptation-guide.md`](./responsive-adaptation-guide.md) 为准。

## 2. 艺术背景保护

资历宝典必须保留 `overview-bg.png` 及其国风视觉：

- 不替换、重绘、裁改或重新着色背景图片；
- 不通过滤镜、模糊、强遮罩或大面积不透明浅色背景改变整体观感；
- 保留原构图方向、深色基调和金棕氛围；
- 页面新增颜色从黑、棕、金、米白色系中协调提取；
- 公共 PVX 的靛蓝主色和浅灰页面底不能机械覆盖该模块；
- 桌面、平板和手机均需检查背景主体没有被异常裁切、完全遮挡或产生断层。

## 3. 页面承载

- `PvxPageShell` 负责页面结构、安全边距和响应式承载。
- 资历宝典专有根节点覆盖 `PvxPageShell` 的默认浅色页面底。
- 画面本体保持透明，现代化集中在工具栏、状态卡、交互控件和滚动容器。
- 艺术背景与现代外围组件保持独立作用域。
- 页面使用自然文档流，不依赖整页固定高度和主区横向滚动。
- 信息密度需要时可以在模块根节点解除公共 `1440px` 上限，但不能修改公共组件默认值。

## 4. 色彩与表面

- 页面基底保持深色国风背景。
- 角色总览和强调区域使用协调的深色半透明表面。
- 分类、表格和表单可以使用暖米色或低透明暖色表面。
- 边框、图标和选中态使用克制的暖金强调。
- 不把页面改造成通用浅色后台风格。
- 内容表面必须保证长正文、表格和状态文字的对比度。

## 5. 信息结构

三页共享“完成进度 / 亲友对比 / 渡劫方案”模块导航：

- 桌面使用侧栏导航；
- 平板和手机改为顶部导航；
- 手机导航共享相同宽度、间距、圆角、背景、触控高度和激活态；
- 导航不得遮挡左侧悬浮菜单或公共 Header。

完成进度按以下层级组织：

1. Hero：标题、当前角色、总资历、总进度和同步说明；
2. 分类概览：完成数、资历点和完成率；
3. 分类路径：显示当前层级与返回关系；
4. 末级成就列表：桌面表格，窄屏使用信息卡或受控局部滚动。

亲友对比将分类、筛选、地图、关键词、角色和导出集中在 Sticky 操作层；横向滚动只能发生在表格自身。

渡劫方案沿用相同的 Hero、暖色面板、分类导航、卡片和表格语言。

## 6. 公共组件

优先复用：

- `PvxPageShell`
- `PvxSurface`
- `PvxSectionHeader`
- `PvxToolbar`
- `PvxActionButton`
- `PvxEmptyState`
- `src/assets/css/design-system/_tokens.less`
- `src/assets/css/design-system/_mixins.less`

公共组件只提供结构能力；资历宝典专有配色必须限定在模块根节点中。

## 7. 响应式验收

至少覆盖：

- 大屏桌面侧栏与表格；
- 窄桌面下工具栏和分类区；
- iPad 顶部模块导航、一级/二级分类和局部横向滚动；
- `414 × 896` 手机；
- 英文和越南文长文本。

所有尺寸都需确认：

- 页面没有整体横向滚动；
- 表格和分类只在明确容器内滚动；
- 背景构图和综合色调保持完整；
- 角色、统计、说明和操作不会互相遮挡；
- 游戏源数据不因布局被截断。
