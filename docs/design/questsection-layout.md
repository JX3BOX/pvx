# 剑侠录页面布局规范

## 1. 适用范围

本文只描述 `/pvx/questsection` 的视觉结构和响应式结果。业务和数据规则见
[`../project/questsection.md`](../project/questsection.md)，通用 PVX 视觉仍以
[`pvx-visual-style-guide.md`](./pvx-visual-style-guide.md) 和
[`responsive-adaptation-guide.md`](./responsive-adaptation-guide.md) 为准。

## 2. 页面结构

页面沿用现代 PVX 资料页结构：

1. 左侧资料片/大章节导航；
2. 右侧头部卡片；
3. 章节分组 Tab；
4. 章节正文卡片；
5. 公共返回顶部组件。

页面使用 `PvxPageShell` 承载安全边距，侧栏、头部和正文使用 `PvxSurface`。背景、边框、圆角、阴影和间距优先使用设计令牌，不建立剑侠录私有色板。

## 3. 页面间距

- 桌面安全边距：`30px`。
- 中等尺寸安全边距：`20px`。
- `≤ 640px` 安全边距：`20px 16px`。
- 手机侧栏、头图、Tab 和正文的模块间距统一为 `@pvx-space-3`。
- 正文内部使用内容 Padding；不得用额外外边距模拟正文留白。

### 3.1 首屏高度与 Footer

- 页面外壳最小高度为 `calc(100dvh - @header-height)`，并保留 `100vh` 回退。
- 公共 `.m-main` 的全屏最小高度必须在剑侠录根节点内重置为 `0`，避免外壳与内容区重复计算视口高度。
- 内容较少时，Footer 应位于首屏下方，不在第一屏露出；内容较多时由自然文档流继续向下撑开。
- 正文和页面外壳不得通过固定高度或大块底部 Padding 人为制造 Footer 前空白。

## 4. 侧栏

- 桌面侧栏为纵向导航卡片，保留资料片折叠和章节列表层级。
- 侧栏在桌面 Sticky，顶部位置避开公共 Header。
- 不把侧栏改成家具列表式横向工具栏。
- 手机按页面顺序先展示导航，再展示内容；普通移动 Web 将资料片和章节折叠列表收为按资料片分组的 Select，避免目录占据首屏，小程序继续保留原侧栏结构。

## 5. 头图

### 5.1 桌面

- 图片显示窗口固定为 `500px × 144px`，加载前后宽度不跳动。
- 素材按自身比例显示，不允许拉伸。
- 可以通过显示窗口裁掉素材右侧无效或透明区域，但不能改变主体比例。
- 标题和年代覆盖在图片左侧，并垂直居中。
- 年代与当前大章节的小节总数同排展示，以中点分隔；缺少年代时只显示小节数。
- 桌面内部图片当前按 `580px` 宽渲染，由 `500px` 窗口承载。

### 5.2 Pad

- 带侧栏时按内容区真实可用宽度收缩图片列。
- 图片列收缩不能把右侧操作区推出容器。
- QQ 机器人最大宽度为 `375px`，并可继续随所在列收缩。

### 5.3 手机

- 图片占满头部卡片内容宽度。
- 不强制设置 `aspect-ratio`。
- 宽度为 `100%`、高度按素材自身比例计算。
- 不使用 `object-fit: fill`，不拉伸、不强制裁切。
- 标题和年代继续覆盖在图片上。

## 6. 桌面头部排列

### `> 1400px`

- 使用“图片 / Tab / 操作区”三列。
- 图片保持固定宽度。
- Tab 与错误反馈顶部对齐。
- Tab 空间不足时只向下换行。
- Tab 区和操作区整体相对图片垂直居中。
- 单行 Tab 也要占据与操作区相近的布局高度，避免被垂直居中到错误反馈下方。

### `1101px - 1400px`

- 第一行放图片和操作区。
- 第二行放章节 Tab，横跨全部列。
- `1101px - 1280px` 进一步改为弹性图片列和安全操作列，适配带侧栏的 Pad/小型笔记本。

### `≤ 1100px`

- 头部降为单列，所有子模块不得制造页面级横向滚动。

## 7. 操作区

- 桌面错误反馈位于 QQ 机器人上方。
- 两者作为同一模块右对齐。
- 错误反馈保持内容宽度，不在桌面无意义拉满。
- QQ 机器人右侧不保留额外边距。
- 普通手机 Web 隐藏整个操作区。

## 8. 章节 Tab

### 桌面和 Pad

- Tab 高度为 `40px`，使用胶囊圆角和 PVX 主色选中态。
- 宽屏允许向下换行。
- Pad 下 Tab 独立占据头部第二行。

### 手机

- 使用独立 Tab 栏，不放在头图 `PvxSurface` 内。
- 单行排列、禁止换行。
- 支持横向触摸滚动，隐藏滚动条。
- 使用 `position: sticky`，`top: @header-height`。
- 使用 `@pvx-radius-panel`，与相邻卡片圆角一致。
- 操作区隐藏后，Tab 紧接头图上移，不保留操作区空位。
- 吸顶背景需保持不透明度和可读性，不让正文穿透影响按钮辨识。

## 9. 正文

- 正文使用独立 `PvxSurface`。
- 每次展示当前分组最多 4 个章节。
- 章节之间使用统一分隔线。
- 标题、正文行高和内容密度与书籍等现代资料详情页一致。
- 页面使用自然滚动，不为正文建立固定高度或内部滚动容器。

## 10. 响应式验收尺寸

至少检查：

- 大于 1400px 的单行 Tab；
- 大于 1400px 的向下换行 Tab；
- 1280px mini book；
- 1133px 左右 Pad；
- 414px 手机；
- 更窄手机下的长标题、最后一组 Tab 和横向滚动。

验收时同时观察图片比例、Tab/错误反馈顶部基线、模块垂直居中、操作区裁切、页面横向滚动和 Sticky 偏移。
