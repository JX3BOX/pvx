# 红尘侠影页面布局规范

## 1. 适用范围

本文描述 `/pvx/partner/:id` 普通 Web 页面的视觉结构、交互和响应式结果。通用颜色、间距和终端规则继续遵循
[`pvx-visual-style-guide.md`](./pvx-visual-style-guide.md) 与
[`responsive-adaptation-guide.md`](./responsive-adaptation-guide.md)。小程序、App 和机器人专用输出不因本文规则被动改变。

## 2. 页面结构与高度

页面由“侠客选择器 / 侠客立绘 / 资料信息”组成。桌面使用三栏 Grid，Pad 将选择器移到顶部并在下方保留等宽双栏，手机依次排列选择器、立绘和资料。

- 页面外壳最小高度为 `calc(100dvh - @header-height)`，保留 `100vh` 回退；内部 `.m-main` 重置 `min-height: 0`，防止重复计算视口高度。
- 桌面安全边距为 `30px`，标准栏间距为 `20px`。
- `1134px–1280px` 使用 `20px` 安全边距、`16px` 栏间距，列宽为 `220px minmax(0, 1fr) 400px`，优先把剩余空间留给中间立绘。
- 桌面和平板资料区允许内部滚动，页面 Footer 仍处于首屏下方；手机恢复自然文档高度。

## 3. 桌面布局

- 宽屏默认列为选择器 `280px`、弹性立绘、资料区 `480px–560px`。
- `≤1400px` 收紧为 `250px / 弹性立绘 / 弹性资料`，但三栏均不得产生页面级横向滚动。
- `1134px–1280px` 隐藏立绘顶部的 QQ 机器人与错误反馈，侠客名称和 ID 保留在立绘左上角。
- 资料区使用独立滚动容器；滚动条贴近面板右边缘，宽 `6px`、轨道透明、滑块使用 PVX 边框色。

## 4. Pad 布局（`769px–1133px`）

- 侠客选择器独占顶部整行；下方立绘与资料区各占一半宽度，间距为 `16px`。
- 顶部选择器隐藏搜索框，侠客改为紧凑横向列表；卡片宽 `72px`、头像 `48px`，支持触摸横向滚动和滚动吸附。
- 第一位侠客与容器左侧保留 `20px` 起始安全间距，末项也应保留对应结束空间。
- 选择器滚动条位于卡片底部边缘，不穿过人物内容。
- 立绘左上角的名称和 ID 隐藏；QQ 机器人、错误反馈和列表展开按钮隐藏。
- 立绘与资料区等宽，高度使用首屏剩余空间，范围为 `420px–560px`；资料内容超出时只在资料卡内部滚动。

## 5. 手机布局（`≤768px`）

- 选择器、立绘、资料区按上下顺序排列，模块间距为 `16px`；`≤640px` 页面安全边距为 `20px 16px`。
- 选择器保留搜索框，人物横向紧凑滚动，第一项左侧同样保留 `20px` 安全间距。
- 立绘上方不显示名称和 ID；立绘之后再展示资料模块。
- 立绘高度不超过 `min(520px, calc(100vw - 32px))`，资料区取消固定高度和内部首屏约束，使用自然文档流。

## 6. 立绘与切换动画

- 背景和人物图片必须在读取自然宽高并完成布局计算后再显示，避免加载阶段按 `100%` 兜底尺寸短暂放大。
- 切换侠客时仅执行克制的透明度淡入，不对背景执行位移、缩放或景深动画。
- 背景始终居中，以 `object-fit: contain` 展示；最大宽高不得超过背景文件的自然像素尺寸。
- 背景加载完成态透明度为 `0.8`。人物立绘同样不得超过自身自然宽高。
- 系统开启“减少动态效果”时取消过渡。

## 7. 资料区视觉与交互

- “基础信息 / 传记”使用互斥分段控件，按钮必须是可聚焦的原生按钮，并提供清晰的选中、Hover 和键盘焦点状态。
- 结识方式、武学招式、武学境界和属性标题采用“左侧 `3px` 靛蓝竖线 + 底部分隔线”，不用大面积淡紫色标题胶囊。
- 技能名称位于卡片左侧，技能类型位于右侧，以浅靛蓝 Tag 表示；不再把类型当作名称下方的次要文字。
- 技能图标统一为 `40px` 点击区，Hover 轻微上浮，选中态使用主色双层描边；不得用进入时自动放大模拟激活。
- 传记折叠面板为手风琴模式，同一时间只展开一项；默认展开首项。
- 武学境界和属性纵向排列，窄宽度下属性字段允许自然换行，不压缩业务文本。

## 8. 验收尺寸

至少覆盖：大于 `1400px`、`1280px` 且浏览器缩放 `125%`、`1133px` Pad、`769px` 临界宽度、`414px` 手机及更窄手机。验收时检查：三栏比例、顶部列表首尾间距、横向滚动、图片自然尺寸、切换时背景稳定、名称/ID 与搜索框显隐、资料区滚动条位置、Footer 首屏位置和页面横向溢出。
